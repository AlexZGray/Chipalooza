# Buffered DAC initial proposal

Initial proposal package for **Chipalooza Challenge #4**, prepared on 12 November 2026. **Status: prepared for team review; not submitted.** Specifications are proposed Sky130 development targets, distinct from the verified functional LTspice reference.

- **[Read the proposal PDF](Chipalooza_DAC6_Initial_Proposal.pdf)**
- [Edit the Word document](Chipalooza_DAC6_Initial_Proposal.docx)

The main document covers the architecture, I/O and test access, harness resources, minimum/typical/maximum targets, external limits, silicon measurement plan and development milestones. It contains no personal or institutional details.

Fill team/contact details in a private submission copy and attach each designer’s actual CV separately. This public package contains no CVs or filled personal information.
